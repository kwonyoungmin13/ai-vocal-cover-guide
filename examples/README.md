# 기록 양식

- [segments.example.csv](segments.example.csv): 후보별 출처·시간·처리·청취 승인·제외 기록
- [cover-settings.example.json](cover-settings.example.json): 커버 실행 설정과 해시·청취 결과 기록
- [separation-constraints.txt](separation-constraints.txt): 분리 환경 설치 예시의 PyTorch 버전 제약

CSV와 JSON은 실제 음원·승인·해시가 들어 있지 않은 예시입니다. 프로젝트의 `data`나 `outputs` 아래에 개인 기록으로 복사해 값을 바꾸세요. 자동 실행기가 읽는 설정 파일은 아닙니다. 실제 청취 전 예시의 승인 상태를 자신의 승인으로 사용하지 않습니다.
