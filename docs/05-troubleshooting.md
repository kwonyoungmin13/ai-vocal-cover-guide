# 5. 막혔을 때 확인할 것

[처음으로](../README.md) · [환경](01-setup.md) · [학습](03-training.md) · [커버](04-cover.md)

## 설치·경로

| 증상 | 확인과 해결 |
|---|---|
| PowerShell에서 스크립트가 차단됨 | 새 작업 세션을 `powershell -NoProfile -ExecutionPolicy Bypass`로 열고 환경 스크립트를 적용합니다. 시스템 정책을 영구 변경할 필요는 없습니다. |
| `No module named audio_separator.__main__` | `python -m audio_separator` 대신 분리 환경의 `Scripts\audio-separator.exe`를 실행합니다. |
| FFmpeg를 찾지 못함 | `tools\ffmpeg\bin\ffmpeg.exe` 위치와 PATH를 확인하고 환경 스크립트를 다시 적용합니다. |
| CUDA가 False, CPU로 실행됨 | 분리 Python과 학습 Python을 각각 확인합니다. GPU·드라이버와 PyTorch CUDA 빌드를 확인한 뒤 짧은 시험을 수행합니다. |
| `No matching distribution` | Python·Windows x64·wheel 지원 여부와 공식 버전 목록을 확인합니다. 실패한 상태에서 다음 설치 단계로 넘어가지 않습니다. |
| 모델 파일을 찾지 못함 | Kim의 파일명은 `vocals_mel_band_roformer.ckpt`입니다. 별칭·공백을 추가하지 않습니다. 모델 목록과 다운로드 폴더를 확인합니다. |
| exFAT에서 `os.link` 오류 | CLI 도움말 실행 전에도 `APPLIO_CONFIG_FILE`을 프로젝트 내부로 지정하고 UTF-8 BOM 없는 `{}` 파일을 미리 만듭니다. |
| 다운로드가 중단됨 | 불완전한 파일을 정상 모델로 취급하지 않습니다. 크기·제작자 해시를 확인하고, 기존 검증 파일을 덮어쓰지 않는 별도 경로에서 재시도합니다. |
| 링크/정션 거부 오류 | 보조 도구는 쓰기 경로의 링크·정션을 허용하지 않습니다. 실제 파일이 있는 일반 프로젝트 폴더를 사용합니다. |

## 전처리·학습

| 증상 | 확인과 해결 |
|---|---|
| 승인 파일보다 전처리 출력이 적거나 많음 | slicer 분할·무음 판정에 따라 수가 달라집니다. 입력과 파생본 대응을 확인하고 설명되지 않는 누락은 중단합니다. |
| RMVPE reflection padding 오류 | 오류를 낸 파생 WAV의 길이·peak를 확인합니다. 원본 승인 WAV를 삭제하지 않습니다. 가청 발성이면 분할 설정을 바꾸고 새 실행을 만듭니다. |
| 특징·F0 파일 수가 맞는데 학습 실패 | 파일명 집합, 배열 차원·유한값·프레임 대응, filelist의 경로를 함께 검사합니다. 개수만 맞춰서는 충분하지 않습니다. |
| `FAISS index` 읽기 오류 | 대응 index의 존재·768차원·벡터 수와 로그를 확인합니다. 인덱스 없이 음원이 출력돼도 의도한 실행의 성공으로 취급하지 않습니다. |
| 정상 진행률 출력인데 PowerShell이 중단됨 | Windows PowerShell 5.1은 stderr 리다이렉션을 오류로 취급할 수 있습니다. 학습 문서의 실행 함수처럼 native 명령 동안 오류 처리 선호를 조정하고 종료 코드·로그를 별도 확인합니다. |
| GPU 메모리 부족 | 중복 GPU 작업을 확인하고 배치를 줄입니다. 데이터/설정이 바뀌면 새 실행 이름을 사용합니다. |
| NaN/Inf 또는 반복 AMP overflow | 로그·가중치·옵티마이저를 검사합니다. 유한한 최종 파일만으로 모든 step이 실행됐다고 판단하지 않습니다. 자동 재학습보다 원인과 청취 결과를 먼저 확인합니다. |
| compact 모델 없이 G/D만 있음 | 완료 epoch/step과 compact 저장 설정을 확인합니다. `G_*.pth`는 추론용 compact 모델과 다릅니다. |

## 음질·믹싱

| 증상 | 확인과 해결 |
|---|---|
| 반주와 음정이 맞지 않음 | -1반음이면 보컬과 반주 모두 -1인지 확인합니다. -12는 한 옥타브이며 -1과 다릅니다. |
| 노래가 빨라지거나 느려짐 | 조옮김에 단순 샘플레이트 변경을 쓰지 않았는지 확인합니다. 속도를 유지하는 피치 변경을 사용합니다. |
| 보컬이 늦거나 중간부터 어긋남 | 시작 지연과 길이 변형을 구분합니다. 두 트랙을 같은 타임라인에서 파형·청취로 확인합니다. 끝 자르기는 정렬을 해결하지 않습니다. |
| 믹스에서 표본율·채널·길이 오류 | 40k→44.1k는 별도 복사본으로 변환합니다. 모노 보컬 복제나 길이 절단은 명시적으로 선택하고 결과를 확인합니다. |
| 발음이 뭉개지거나 금속성 잡음 | 원 가이드·분리·잔향 제거·RVC를 각각 들어 문제 발생 단계를 찾습니다. 한 단계의 설정만 바꿔 대표 구간으로 비교합니다. |
| 고음에서 목소리가 불안정함 | 해당 음역의 승인 자료가 충분한지, 가이드에 화음·악기 잔여가 있는지 확인합니다. 학습 epoch만 늘려 해결된다고 가정하지 않습니다. |
| A/B 중 한쪽이 더 좋게 느껴짐 | 같은 시간 구간과 비슷한 음량으로 비교합니다. 과도한 증폭을 피하고 큰 쪽을 감쇠합니다. |
| `technical_ok: true`인데 듣기 나쁨 | 이 값은 전체 디코드·프레임·유한값 검사입니다. 목소리 유사도·발음·음악적 자연스러움을 판정하지 않습니다. |

문제를 기록할 때는 실행 단계, 입력 종류, 도구 버전, 변경한 설정, 오류 직전 로그를 남깁니다. 토큰·개인 경로·음성 파일이 포함되지 않았는지 확인한 후 Issue에 공유하세요.
