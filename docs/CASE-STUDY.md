# 수행 사례: 보컬 정리부터 RVC 학습·커버 완성까지

2026년 10월 16~17일 Windows PC에서 진행한 프로젝트의 작업 기록이다. 숫자는 해당 컴퓨터와 입력의 측정값이며, 다른 목소리·GPU·음원에 대한 성능이나 품질 보장이 아니다. 이 문서에는 원음, 분리 보컬, 학습 자료, 가수 모델, 완성 커버 파일을 포함하지 않는다.

## 환경

| 항목 | 당시 사용 환경 |
| --- | --- |
| OS / CPU / RAM | Windows 11 Home 64비트 / i5-12400F / 32GB |
| GPU | NVIDIA RTX 5060 8GB |
| 작업 저장장치 | USB 연결 exFAT |
| Python / FFmpeg | 3.12.10 / 9.0.2 |
| 분리 환경 | audio-separator 0.47.0, torch 2.13.0+cu130 |
| 학습 환경 | torch 2.11.0+cu130, torchaudio 2.11.0+cu130, NumPy 2.4.6 |
| 학습 엔진 | Applio `e95ec175db434011854efc3b1bd66088b4d1e379` |

분리와 학습은 서로 다른 가상환경에서 실행했다. 당시 설치된 패키지 기록과 소스·모델 해시를 남겼다. 공개 가이드는 이 기록을 참고하되, 다른 컴퓨터에서 의존성·CUDA·실제 GPU 연산을 다시 확인하는 절차를 제공한다.

## 작업 흐름과 수량

1. **20곡 보컬 분리.** 기존 두 곡을 보존하고 나머지 18곡을 한 곡씩 처리했다. Kim vocals Mel-Band Roformer, CUDA native FP16, batch 1, overlap 4, 모델 기본 11초, compile 비활성화를 사용했다. 출력은 44.1kHz 스테레오 PCM24 WAV다.
2. **대표 구간 4개로 잔향 제거 비교.** 곡당 15초를 Sucial De-Reverb-Echo V2로 처리하고 음량을 맞춘 A/B를 먼저 들었다. 사용자가 방법을 승인한 뒤 전체 20곡을 별도 폴더에 처리했다. 분리 보컬 원본은 덮어쓰지 않았다.
3. **19곡에서 후보 439개 수집.** 사용자가 먼저 제외한 한 곡을 빼고 3~15초 후보를 만들었다. 총 길이는 문맥·일부 겹침을 포함해 68분 52.28초였다. 자동 추출은 후보만 만들었고, 청취 화면에서 사람이 검토했다.
4. **17곡 398개 승인.** 추가로 두 곡을 제외하고 62분 17.18초의 승인 원본을 확정 폴더에 복사했다. 당시 제외 곡은 Go, Go!, Life, 사랑의 시다. 모든 후보와 제외 원본을 보존했다.
5. **학습 파생본 검증.** Automatic slicer가 승인 원본 4개를 무음으로 판단해 출력을 만들지 않았다. 다른 한 원본에서는 0.06초·peak 약 `4.48e-8`의 비가청 잔여만 생성됐다. 해당 파생 WAV와 특징을 SHA와 함께 보관하고 승인 원본은 유지했다.
6. **실제 학습.** 393개 입력·17곡에서 파생 WAV, 특징, coarse F0, continuous F0가 각각 1,519개 생성됐다. filelist는 무음 자산 2행을 포함해 1,521행이었다. 768차원 인덱스는 192,249개 벡터로 검증했다.
7. **100 epoch 완료.** RVC v2·40kHz·RMVPE·contentvec·HiFi-GAN, batch 4, 10 epoch마다 저장으로 38,200 step까지 진행했다. 최종 모델·인덱스와 G/D 체크포인트를 보관하고 약 7.98초 자기보컬 재변환을 기능 시험했다.
8. **독립 커버 제작.** 새 노래의 가이드 보컬을 분리·잔향 제거한 뒤 기존 모델로 변환했다. 먼저 동일 구간 20초로 키를 비교하고 전곡을 처리했다. 윤하 「사건의 지평선」은 원곡키와 -1반음 버전, 우디 「어제보다 슬픈 오늘」은 원곡키 버전을 만들었다. 재학습이나 학습 자료 추가는 하지 않았다.

학습의 승인 원본 수, 전처리가 사용한 원본 수, 파생 WAV 수, filelist 행 수는 서로 다른 값이다. 무음 자르기와 overlap이 있기 때문에 단순히 원본 총길이에서 12초를 빼서 실제 학습 분량을 구하지 않았다.

## 커버 변환과 믹스

RVC 추론은 `index_rate=0.3`, `protect=0.33`, `volume_envelope=1.0`, RMVPE·contentvec을 사용했다. 긴 입력은 중앙 25초, 좌우 1초 문맥, 경계 100ms crossfade로 고정 시간축에 조립했다. 전곡 길이와 경계 coverage를 검사하고 envelope 상관관계로 지연을 참고 진단했다.

원곡키는 보컬과 반주 모두 0반음이었다. -1반음 버전은 보컬과 반주를 함께 -1반음으로 내려 조성을 맞췄다. -12반음은 한 옥타브이며 -1반음과 다르다. 키 비교본은 같은 구간을 낮은 RMS 쪽으로 감쇠해 음량 차이를 줄였다.

보컬 gain 0dB, 추가 EQ·압축·리버브 없이 합산한 뒤 공통 감쇠로 sample peak를 -1dBFS에 맞췄다. 완성본은 44.1kHz 스테레오 PCM24 WAV와 320kbps MP3였다. 손실압축 원음을 24비트로 저장하거나 PCM16 추론 결과를 FLOAT/PCM24로 조립해도 이미 잃은 정밀도가 복원되지는 않는다.

## 검사 결과와 남은 판단

20곡 분리본의 형식·길이·전체 디코딩·유한값·출처 연결·무결성 검사가 20/20 통과했다. 커버도 전체 디코딩, 원음과 길이·채널 일치, 비유한값·fullscale sample 검사, 원음·모델·기존 결과의 SHA 보존 대조를 통과했다.

학습은 최종 모델과 G/D 가중치의 유한성 및 100 epoch 종료 기록 검증을 통과했다. 별도 품질 감사에는 간헐적인 AMP overflow/scale 조정과 G 25회·D 5회의 optimizer step 결손 증거가 남아 `needs_review`로 기록했다. 이를 곧바로 음질 실패나 자동 재학습 사유로 판정하지 않았다.

최종 커버의 실제 목소리 유사도, 고음, 발음, 원보컬 잔여, 보컬·반주 균형은 사용자 청취 대상이었다. 차이 반주는 분리 보컬의 내부 음량 조정에 따라 원보컬 잔여가 생길 수 있다. 기술 검사를 청취 품질 보장으로 표현하지 않았다.

## 따라 할 때 남겨야 할 기록

실행마다 입력 출처·사용 권한, 원본 SHA, 승인 목록, 제외 이유, 모델·엔진 버전, 실제 명령, 설정, 단계별 로그, 결과 SHA, 기술 검사, 청취 판단을 남긴다. 실패 메시지를 지우기보다 과거 오류와 최신 상태를 구분하고, 수정본은 새 실행명에 저장한다.

공개 저장소에는 방법·도구·설정 예제만 올린다. 개인 작업 경로, 다운로드 음원, 승인 클립, 학습 모델, 완성 커버, 인증 정보가 포함되지 않았는지 별도 확인한다.
